# 밑빠진 독상 (dokseong)

함께하는 시민행동 **밑빠진 독상** 페이지. 2000년 제1회부터 2025년 제40회까지 이어온
예산낭비 감시 활동을, 제41회부터 **시민 제보와 투표**로 함께 만들어가기 위한 사이트입니다.

- 조직 홈페이지: https://action.or.kr
- 현재 배포: 아직 없음 (로컬 파일로만 확인)

## 구조

```
dokseong/
├── index.html   # 페이지 전체 (HTML + CSS + JS 한 파일)
├── img/         # 이미지 자리 (아직 비어 있음)
└── README.md
```

`index.html` 한 파일에 스타일과 스크립트가 모두 들어 있습니다.
앞으로 투표·캠페인 요소가 늘어나면 `assets/css`, `assets/js`로 분리할 예정입니다.

## 페이지 섹션

| 섹션 | id | 상태 |
|---|---|---|
| 히어로 | — | 문구 완성, 사진 없음 |
| 제41회 투표 | `#vote` | **더미 후보 5개**, 집계는 브라우저 안에서만 (새로고침하면 초기화) |
| 역대 수상 | `#history` | 카드 + 1~40회 전체 표 토글 |
| 시민 제보 | `#report` | 폼 UI 완성, **전송 대상 없음** |
| 후원 CTA | — | 링크 미정 |

## 지금 비어 있는 것 (작업 대기)

1. **이미지 2개** — `img/logo.png` (시민행동 로고), `img/dok-hero.jpg` (히어로 사진).
   지금은 깨진 이미지로 보입니다.
2. **제보 폼 전송** — `index.html` 하단 `REPORT_FORM` 객체의 `action`과 `entries`가 빈 문자열입니다.
   구글 폼 `formResponse` URL과 `entry.NNNN` ID를 넣으면 바로 동작합니다.
   (구글 폼 말고 자체 DB로 갈지는 아직 결정 전)
3. **투표 집계** — 현재는 데모입니다. `data-votes` 숫자가 하드코딩돼 있고 서버 저장이 없습니다.
   실제 투표를 받으려면 백엔드가 필요합니다.
4. **투표 후보** — 제41회 후보가 확정되면 `.vote-item` 5개를 실제 사업으로 교체.
5. **GA4** — `G-XXXXXXXXXX` 자리표시자. 측정 ID 발급 후 2곳 교체.
6. **홈/후원 링크** — `href="index.html"`, `href="index.html#donate"`가 이 페이지 자신을 가리킵니다.
   시민행동 홈페이지의 실제 주소로 교체 필요.

## 로컬에서 보기

```bash
python -m http.server 8000
# http://localhost:8000
```

파일을 더블클릭해서 열어도 되지만, 폰트·이미지 경로 확인은 서버로 띄우는 쪽이 정확합니다.
