# 밑빠진 독상 (dokseong)

함께하는 시민행동 **밑빠진 독상** 사이트. 2000년 제1회부터 2025년 제40회까지 이어온
예산낭비 감시 활동을, 제41회부터는 **분기마다** 시민 제보와 투표로 함께 만들어갑니다.

```
제보 접수 → 후보 선정 → 시민 투표 → 수상 발표 → 캠페인 서명 → (다음 분기)
```

## 구조

```
dokseong/
├── public/
│   ├── index.html          # 페이지 전체 (HTML + CSS + JS 한 파일)
│   ├── privacy.html        # 개인정보 처리방침 (초안 — 채워야 할 곳이 있음)
│   └── data/
│       ├── map-sido.json       # 시도 17개 (SVG 경로)
│       ├── map-sigungu/        # 기초자치단체 229개 (아직 화면에 안 씀)
│       └── awards.json         # 역대 수상 40건 + 지역 코드
├── functions/
│   └── api/
│       ├── report.js       # POST /api/report  — 시민 제보 접수
│       └── regions.js      # GET  /api/regions — 지역별 제보 건수
├── tools/                  # 지도·수상 데이터 만드는 스크립트
├── schema.sql              # D1 테이블 정의
└── wrangler.toml           # Cloudflare Pages 설정 · 회차 번호
```

**Cloudflare Pages + Functions**를 씁니다. 빌드 단계가 없습니다 —
`public/`은 그대로 서비스되고, `functions/` 안의 파일 하나가 그대로 API 주소가 됩니다
(`functions/api/report.js` → `/api/report`).

> 예산게임(budget-mbti)의 Vite + Worker 구성은 일부러 따라가지 않았습니다.
> 로컬에서 DB 붙이는 것만도 손이 많이 가는 구조라, 여기서는 단순한 쪽을 골랐습니다.

## CSS 범위 규칙 (중요)

나중에 이 페이지를 **캠페이너스 홈페이지 안에 통째로 붙여넣을** 예정입니다.
그래서 모든 CSS 규칙이 `#dok` 안에 갇혀 있고, 클래스는 전부 `dok-` 로 시작합니다.

- ❌ `.card { ... }`, `body { ... }`, `* { ... }`
- ✅ `#dok .dok-card { ... }`

전역 선택자를 쓰면 붙여넣는 순간 홈페이지 전체 레이아웃이 깨집니다.
전역 규칙은 `html { scroll-behavior }` 하나뿐이고, 이식할 때 그 줄만 지우면 됩니다.
이식 단위는 `public/index.html` 안의 `<div id="dok">` … `</div>` 통째입니다.

## 예산감시 사업 내용 고치는 법

분기마다 손대는 곳은 `public/index.html` 안 두 군데입니다. **코드는 건드리지 않습니다.**

1. **목록** — `<script type="application/json" id="dok-campaign-data">`
   카드에 보이는 제목·요약·기간·상태(`ongoing`/`closed`)·결과 한 줄.
2. **상세 내용** — `<div id="dok-camp-bodies">` 안의 `<article data-camp="아이디">`
   카드를 눌렀을 때 열리는 보고서 본문. 그냥 HTML이라 `<h4>`, `<p>`, `<a>`를
   평소처럼 쓰면 됩니다. JSON 안에 긴 글을 넣으면 줄바꿈·따옴표 때문에
   쓰기 어려워서 일부러 나눴습니다.

두 곳의 **`id`와 `data-camp` 값이 같아야** 연결됩니다.
`<article>`이 없으면 "아직 정리된 내용이 없습니다"가 뜨고, 오류가 나지는 않습니다.

- 진행 중인 사업 → 무엇이 문제인지, 지금까지 확인한 것, 앞으로 할 일
- 종료된 사업 → 무엇이 문제였는지, 무엇이 남았는지 (+ `outcome` 한 줄이 강조돼 표시됨)

## 지도

17개 시도까지만 그립니다. 지도를 누르거나, 아래 **지역 칩**을 눌러 지역을 고릅니다.
칩이 따로 있는 이유는 모바일(334px)에서 인천·대전·세종 같은 작은 시도를
손가락으로 누를 수 없기 때문입니다. 지도는 보는 것, 칩은 누르는 것입니다.

기초자치단체(시군구) 드릴다운은 데이터가 이미 `public/data/map-sigungu/`에
준비돼 있고, 행정구역 변경분을 반영한 뒤에 붙일 예정입니다.

지도 데이터를 다시 만드는 방법은 [tools/README.md](tools/README.md)를 보세요.

## 회차 관리

분기마다 바뀌는 값은 코드가 아니라 `wrangler.toml`의 `[vars]`에 있습니다.

| 변수 | 뜻 |
|---|---|
| `CURRENT_ROUND` | 지금 진행 중인 회차 (제41회 = `"41"`) |
| `REPORT_OPEN` | `"0"`으로 두면 제보 접수가 닫힘 |

## 처음 한 번 해야 하는 세팅

```bash
# 1. D1 데이터베이스 만들기
npx wrangler d1 create dokseong
#    → 출력된 database_id를 wrangler.toml에 붙여넣기

# 2. 테이블 만들기
npx wrangler d1 execute dokseong --remote --file=schema.sql

# 3. IP 해시용 소금값 (제보자 IP를 원본으로 저장하지 않기 위함)
npx wrangler pages secret put IP_SALT
```

## 로컬에서 보기

```bash
npx wrangler pages dev public --d1 DB=dokseong
npx wrangler d1 execute dokseong --local --file=schema.sql   # 최초 1회
```

DB 없이 화면만 볼 거면 `python -m http.server 8000 -d public` 으로도 충분합니다
(제보 폼만 동작하지 않습니다).

## 개인정보 처리방침 (`public/privacy.html`)

기후솔루션의 방침을 뼈대로 삼아 시민행동에 맞게 옮긴 **초안**입니다.
이 사이트가 실제로 수집하는 항목(예산낭비 제보, 캠페인 서명, 투표)을 반영해
목적·항목·보유기간 조항을 추가했습니다.

**공개 전에 반드시 채워야 하는 곳이 16군데 있고, 노란 배경으로 표시돼 있습니다.**
기후솔루션의 사실관계(위탁업체 목록, HubSpot 국외이전, 개인정보보호 책임자 김주진
대표이사, 연락처, 시행일)를 그대로 옮기면 시민행동에 대해 거짓이 되므로 비워 뒀습니다.

별첨으로 **캠페인 소식·후원 정보 수신 동의문**이 들어 있습니다.
서명 양식을 만들 때 이 문구를 그대로 씁니다.

> **수신 동의는 원문대로 '필수'로 갑니다** (2026-08-20 사용자 결정).
> 캠페인 참여에 꼭 필요하지 않은 홍보성 수신 동의를 필수로 걸면 개인정보 보호법상
> 문제가 될 수 있다는 점은 사용자가 알고 있으며, 나중에 필수/선택으로 나눌 수 있게
> `privacy.html` 안에 HTML 주석으로 근거를 남겨 두었습니다.
