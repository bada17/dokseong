# 제보 접수처 — 구글 스프레드시트 붙이기

밑빠진 독상 제보 폼이 보낸 것을 **구글 스프레드시트에 한 줄씩** 쌓습니다.
사진은 구글 드라이브에 들어가고 시트에는 링크만 남습니다.
지도에 뜨는 지역별 건수도 이 시트에서 셉니다.

**시트가 곧 검토실입니다.** 따로 관리자 화면을 만들지 않습니다 —
정적 페이지 한 장이라 서버도 로그인도 없고, 소스에 비밀번호를 넣으면 그대로 보입니다.

> 왜 시트인가 — **검토를 여러 사람이 나눠 하기 때문입니다.**
> 담당자 컴퓨터에서만 도는 `tools/review.py` 로는 한 사람밖에 못 봅니다.
> 시트는 계정만 나눠 주면 여럿이 동시에 보고, 누가 무엇을 봤는지도 남습니다.

---

## 붙이는 순서 — 브라우저에서 한 번에 (10분)

**나가지 말고 끝까지 이어서 하세요.** 중간에 나가면 나중에 다시 들어와야 합니다.

### 1. 시트 만들기

**`action@action.or.kr` 계정으로 로그인한 채로** <https://sheets.new> 를 엽니다.
이름을 `밑빠진 독상 제보` 로 바꿉니다.

⚠️ 개인 지메일로 만들지 마세요. 단체 자료가 개인 계정에 얹히면 나중에 옮기기 어렵습니다
(참여예산 상담소에서 한 번 겪어 결국 새로 만들었습니다).

⚠️ 탭 이름은 그대로 둬도 됩니다. `제보` 탭은 다음 단계에서 저절로 생깁니다.

### 2. 스크립트 붙이고 `setUp` 한 번 실행

**확장 프로그램 › Apps Script.** 안에 있던 것을 다 지우고 이 폴더의
[`Code.gs`](Code.gs) 를 통째로 붙여넣습니다. 저장(Ctrl+S).

맨 위 세 줄만 확인하면 됩니다 —

| 값 | 뜻 |
| --- | --- |
| `NOTIFY_TO` | 알림 메일을 받는 곳 (`action@action.or.kr`) |
| `CURRENT_ROUND` | 지금 도는 회차. **분기가 바뀌면 올리고 새 버전으로 배포** |
| `PHOTO_ROOT` | 사진이 들어갈 드라이브 폴더 이름 |

그다음 **편집기 위쪽 함수 고르는 칸에서 `setUp` 을 골라 ▶ 실행.**
권한을 묻는 창이 뜹니다 — 시트·드라이브·메일 셋을 허용하세요
(사진을 드라이브에 넣고 알림 메일을 보내기 때문입니다).

> '이 앱은 확인되지 않았습니다' 가 뜨면 **고급 › (안전하지 않음) 이동**.
> 내가 방금 붙여넣은 스크립트라 확인 절차를 안 거쳤을 뿐입니다.

실행이 끝나면 **아래 '실행 로그'에 나눠 줄 주소 둘이 찍힙니다.**
`제보` 탭과 사진 폴더도 이때 만들어집니다 — 첫 제보를 기다릴 필요가 없습니다.

### 3. 배포하기

**배포 › 새 배포 › ⚙️ › 웹 앱**

| 칸 | 값 |
| --- | --- |
| 실행 계정 | **나** (시트 주인) |
| 액세스 권한 | **모든 사용자** |

⚠️ '모든 사용자'가 아니면 `/exec` 가 **403** 이 나고 폼이 조용히 실패합니다.
   참여예산 상담소에서 이걸로 한 번 막혔습니다.

배포가 끝나면 나오는 **웹 앱 URL**(`https://script.google.com/…/exec`)을 복사해 둡니다.
**이 주소가 마지막에 필요합니다.**

### 4. 나눠 주기 (2번의 실행 로그에 주소가 있습니다)

| 무엇 | 누구에게 | 권한 |
| --- | --- | --- |
| 시트 | 검토하는 사람들 | **편집자** (상태를 바꿔야 합니다) |
| 사진 폴더 `밑빠진 독상 제보 사진` | 검토하는 사람들 | **뷰어** (읽기만) |

⚠️ **둘 다 '링크가 있는 모든 사용자'로 열지 마세요.**
   시트에는 회신용 이메일이, 폴더에는 제보 사진이 들어 있습니다.
   사람을 하나씩 더하는 방식만 씁니다.

⚠️ 폴더를 안 나눠 주면 다른 검토자가 시트의 사진 링크를 눌러도 열리지 않습니다.
   회차 폴더(`제41회`)는 그 아래에 생기므로 **위 폴더만 한 번** 나눠 주면 됩니다.

### 5. 웹 앱 주소를 화면에 넣기 — **여기부터는 Claude 가 합니다**

3번에서 복사한 `/exec` 주소를 주면 나머지는 이쪽에서 합니다 —

1. `public/index.html` 의 `DOK_SHEET_ENDPOINT` 에 넣고 (이 한 줄이 폼의 빗장입니다)
2. `curl` 로 접수처가 열렸는지 확인하고
3. 시험 제보를 한 건 보내 시트에 실제로 쌓이는지 보고 (그 줄은 지우면 됩니다)
4. 커밋합니다

배포만 사람 손이 필요합니다 —

```bash
npx wrangler pages deploy public --project-name dokseong --branch main --commit-dirty=true
```

⚠️ 출력에 `Using redirected Wrangler configuration` 이 나오면 **멈추세요.**
   `.wrangler/deploy/config.json` 이 `wrangler.toml` 을 가로챈 것입니다. 지우고 다시 배포합니다.

## 검토하는 법 — 시트에서

시트 오른쪽 네 칸이 검토 칸입니다.

| 칸 | 누가 채우나 |
| --- | --- |
| `상태` | 사람이 고릅니다 (드롭다운) |
| `검토한 사람` | **저절로 채워집니다** — 상태를 바꾼 사람의 계정 |
| `검토한 날` | **저절로 채워집니다** |
| `메모` | 사람이 적습니다 |

상태 다섯 가지입니다. 옛 D1 설계의 `new/reviewing/candidate/dropped/spam` 을 그대로 옮긴 것입니다.

| 상태 | 뜻 | 지도 |
| --- | --- | --- |
| `접수` | 아무도 안 봤음 | ✗ |
| `검토중` | 담당자가 읽고 넘겼음 | **✓** |
| `후보` | 이번 회차 후보로 채택 | **✓** |
| `탈락` | 후보 탈락 | ✗ |
| `스팸` | 장난·광고 | ✗ |

**접수는 자동이고 표시만 사람이 엽니다.** 장난 제보 한 건에 지역 색이 바뀌면
지도를 믿을 수 없게 되기 때문입니다.
⚠️ 그래서 **아무도 상태를 안 바꾸면 지도는 계속 0건**입니다.

여럿이 나눠 볼 때 —

- 밀린 것만 보려면 **필터 보기**를 씁니다 (`상태 = 접수`).
  필터 '보기'는 나만 보는 것이라 남의 화면을 건드리지 않습니다.
- 회차별로 보려면 `회차 = 41` 로 거릅니다. **탭을 회차마다 나누지 않습니다** —
  나누면 밀린 것을 한 곳에서 훑을 수가 없습니다.
- `검토한 사람` 칸이 채워져 있으면 누가 이미 봤다는 뜻입니다. 겹쳐 읽지 마세요.

`검토한 사람` 이 비어 있는 경우가 있습니다. 같은 도메인(`action.or.kr`) 밖 계정으로
고치면 구글이 누구인지 알려주지 않기 때문입니다. 그때는 손으로 적으면 됩니다.

⚠️ **칸을 새로 끼워 넣거나 순서를 바꾸지 마세요.** 받는 코드가 열 번호로 찾습니다 —
   `상태` 는 10번째 칸, `시도코드` 는 4번째 칸입니다. 하나만 밀려도 지도가 0건이 되고
   새 제보가 엉뚱한 칸에 들어갑니다. 적을 곳이 더 필요하면 **`메모` 칸을 쓰거나**
   맨 오른쪽(`메모` 뒤)에 더하세요. 그 뒤는 코드가 안 봅니다.

## 고칠 때

`Code.gs` 를 고친 뒤에는 **배포 › 배포 관리 › ✏️ › 새 버전**.
**'새 배포'를 누르면 주소가 바뀌어** `DOK_SHEET_ENDPOINT` 도 같이 고쳐야 합니다.

이미 만들어진 `제보` 탭에는 꾸미기가 다시 걸리지 않습니다(`setUp` 을 다시 눌러도
탭이 이미 있으면 그냥 지나갑니다). 머리글·드롭다운을 다시 걸려면 편집기에서 직접 부릅니다 —

```js
setUpSheet(SpreadsheetApp.getActiveSpreadsheet().getSheetByName('제보'))
```

⚠️ 이건 머리글을 **한 줄 더 쌓습니다.** 쌓인 줄이 있을 때는 쓰지 마세요.

## 아직 안 한 것

- **보관 기간이 지난 줄 자동 삭제.** 개인정보 처리방침에는 회차 종료 후 1년,
  회신용 이메일은 안내를 마치면 곧바로 지운다고 적어 두었는데 **지우는 코드가 없습니다.**
  적어만 두고 안 지우면 사실상 영구 보관입니다. 주소를 널리 뿌리기 전에 맞추는 게 좋습니다.
  ⚠️ 그 1년·6개월은 Claude 가 제안한 값이라 담당자 확인이 필요합니다
  (`public/privacy.html` 에 주석으로 표시해 두었습니다).
- **하루 접수 상한.** Apps Script 는 접속한 IP 를 알려주지 않아 D1 시절의
  IP 기준 제한을 그대로 옮길 수 없었습니다. 지금 막는 것은 허니팟과 최소 길이 둘뿐이고,
  가짜 줄이 쌓이면 `스팸` 으로 표시해 걸러 냅니다.
- **조건부 서식** — `상태` 가 `접수` 인 줄에 색.

## 안 하기로 한 것

- 관리자 웹페이지 (공개 주소에 제보자 정보로 들어가는 문을 만들지 않습니다)
- 회차마다 탭 나누기 (밀린 것을 한 곳에서 못 봅니다)
- 사진 폴더를 링크 공개로 열기
