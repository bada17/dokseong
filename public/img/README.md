# 사업 이미지 두는 곳

`public/index.html` 안 캠페인 JSON의 `"image"`에 파일 이름을 적으면 그때부터
카드와 상세 팝업에 사진이 나옵니다. 비워 두면 "이미지 자리" 표시가 대신 나옵니다.

```json
{
  "title": "검찰 특수활동비 감시",
  "image": "img/teukhwalbi.jpg",
  "image_alt": "검찰 특수활동비 규탄 기자회견 현장"
}
```

- **비율** 카드는 16:9로 잘라서 보여줍니다. 가로로 긴 사진이 좋습니다.
- **크기** 가로 1200px 정도면 충분합니다. 원본을 그대로 올리면 모바일에서 느려집니다.
- **`image_alt`** 화면을 못 보는 분에게 읽어 주는 설명입니다. 비워 두면 사업명이 대신 읽힙니다.
- 저작권이 확인된 사진만 올려주세요. 집회·기자회견 사진은 인물이 특정되지 않게 살펴봐야 합니다.
